Stack acordado
--------------
- Frontend: HTML + CSS + JavaScript puro (sin frameworks).
- Backend: Google Apps Script (Web App, doPost/doGet).
- Persistencia: Google Sheets (7 hojas: REGISTROS, MUNICIPIOS,
  LOCALIDADES, USUARIOS, CATALOGOS, SEGUIMIENTOS, SESIONES).
- Deploy: GitHub Pages (estático) + Apps Script como API.
- Auth: usuario/clave contra hoja USUARIOS (SHA-256 con salt).
- Sesión: token UUID hex 32 chars en hoja SESIONES, expira 7 días.
- Sin BD externa, sin Node, sin Docker, sin frameworks.
